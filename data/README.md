# Data provenance

`raw/` contains unchanged public IBM/Skills Network educational snapshots downloaded during maintenance. URLs, timestamps, byte lengths and SHA-256 hashes are recorded in `source_manifest.json`.

| File | Purpose |
|---|---|
| dataset_part_1.csv | 90-launch normalized analytical input; payload is already imputed upstream |
| dataset_part_2.csv | Independently supplied course labels, used only to reconcile the derived target |
| spacex_launch_dash.csv | Separate 56-launch dashboard population |
| spacex_launch_geo.csv | Separate 56-row geographic/course reference table; not a fresh scrape |

`processed/launches.csv` is generated by `python -m scripts.run_analysis`; it preserves launch-level source values and adds parsed date, year and the explicitly mapped course target. No raw snapshot is overwritten.

Live SpaceX and Wikipedia collectors are optional. `data/live/` is ignored by Git, and fresh results are not silently substituted for the historical snapshots. The raw launch API has nested entity IDs; rebuilding an enriched historical CSV requires additional entity lookups and scope reconciliation, which are not claimed here.

Course target 1 includes True ASDS, True RTLS and True Ocean. Target 0 includes false, unknown and no-attempt outcomes. This label is not identical to successful hardware recovery.

Third-party datasets retain upstream rights; the repository code license does not relicense them. Public availability is not a claim of unrestricted reuse. See IBM Skills Network course materials for context.
